# 만 4세 플레이테스트 — 결과와 요구사항

대상: 만 4세 남아, 아빠 폰(Galaxy Z Fold7, 가로), 10분.
방법: 현재 빌드의 실제 화면 11장과 계측된 동작을 근거로 4세 페르소나 에이전트가 반응.

> 상상으로 만든 피드백이 아니라 실제 화면을 보고 나온 반응입니다. 다만 **진짜 아이가 아닙니다** —
> 손가락 오조작 빈도나 실제 체감 공포 같은 건 여전히 실기 관찰이 필요합니다.

## 한 줄 요약

> "나 아무것도 못 해. 그냥 보기만 해. **보기만 하는 건 유튜브랑 똑같아.**"

10초 만에 창밖을 봤고, 두 번째 전투부터는 화면을 안 보고 손가락으로 문지르기만 했습니다.
보스전 도중에는 폰을 내려놓고 물 마시러 갔다가 돌아왔는데 아직 안 끝나 있었습니다.

## 아이가 말한 것 중 사실 확인한 것

측정해보니 원인이 말과 다른 게 두 개 있었습니다. **증상은 진짜였고 원인 지목이 틀렸습니다.**

| 아이 말 | 실제 원인 |
|---|---|
| "공룡이 투명해. 유령 같아" | 공룡은 불투명합니다 (renderQueue 2000, alpha 1.00). 초록 안개 + **팀 링(알파 0.20)이 여러 장 겹치면서** 창백해 보이는 것 |
| "거미가 졌는데 왜 화면이 거미를 보여줘?" | 카메라는 정확히 생존자(Bio T-Rex, Red)를 골랐습니다. 문제는 **거미 사망 애니메이션이 몇 초 동안 선 자세를 유지**하는 것 — `inDeathState=True, normalizedTime=0.27, rotX=0`. 승리 화면 한가운데 진 쪽이 멀쩡히 서 있음 |
| "나 아무것도 못 해" | 사실이고, **의도된 설계**입니다 (관전형) |

## 요구사항

### A군 — 명백한 결함. 설계와 충돌 없음

| # | 요구사항 | 근거 (아이 말) |
|---|---|---|
| A1 | 버튼을 누르면 **눌린 티가 나야** 한다 (색 변화 + 소리) | "삑 소리도 안 나. 눌린 건지 몰라서 **다섯 번 눌렀어**" |
| A2 | 버튼에 **그림/아이콘**이 있어야 한다. 글씨만으로는 안 된다 | "글씨야. 나 글씨 못 읽어. 그림도 없어" |
| A3 | **종료에 확인창**이 필요하다 | "옆에 있는 거 눌렀더니 **게임이 아예 꺼졌어. 나 안 껐어!**" |
| A4 | 전투 중 `다시 하기`/`종료`를 화면 **정중앙 상단에서 치워야** 한다 | "손이 자꾸 거기 닿아. 딱 가운데 위에 있어서" — 실수로 눌러 판을 날림 |
| A5 | **배경음악**과 전투 긴장감 사운드 | "노래가 아예 없어. 조용하니까 좀 이상해" |
| A6 | 승리 시 **축하 연출** (파티클 + 소리 + 승자 포효) | "이겼는데 그냥 까만 네모만 떠. 재미없어. **색종이 팡!**" |
| A7 | 결과 패널이 **승자를 가리면 안 된다** | "까만 네모가 화면 가려. 뒤에 뭐 있는데 안 보여" |
| A8 | 보스 사망이 **죽은 것처럼 보여야** 한다 | 위 표 참고. 거미가 서서 죽음 |
| A9 | 안개/팀 링 때문에 공룡이 **창백하게 묻히는 것** 개선 | "화면이 다 초록색이야. 하늘도 초록, 땅도 초록" |
| A10 | 전투 시작 시 공룡이 **너무 작다** | "저어어 멀리 **개미만 해.** 얼굴 안 보여" |
| A11 | **내 팀이 어디인지** 알려줘야 한다 | "내 거 어떤 거야?" ← 세 번 물어봄 |
| A12 | 공룡 **이름을 보여줘야** 한다 | "이 게임엔 공룡 이름이 하나도 없어. 나 공룡 이름 배우고 싶은데" |

### B군 — 관전형을 깨지 않는 범위의 상호작용

핵심 불만은 "만질 수 없다"입니다. 전투를 조작하게 하면 이 게임이 아니게 되지만,
**조작이 아닌 반응**은 줄 수 있습니다.

| # | 요구사항 | 근거 |
|---|---|---|
| B1 | 공룡을 누르면 **포효**한다 (전투에 영향 없음) | "눌렀을 때 **크아앙!** 하면 좋겠어. 눌렀는데 아무 일도 안 일어나면 그건 게임 아니야" |
| B2 | 공룡을 누르면 **카메라가 그 공룡을 따라간다** | "내가 티라노 보고 있는데 화면이 저쪽으로 가버려. 내가 보고 싶은 애를 계속 보게 해줘" |

### C군 — 소유자 결정 필요. 이전 지시와 충돌하므로 임의로 하지 않음

아이가 가장 강하게 원한 것들인데, **전에 직접 내리신 결정과 정면으로 부딪힙니다.**
그래서 물어보고 진행합니다.

| # | 아이가 원한 것 | 충돌하는 이전 결정 |
|---|---|---|
| C1 | **티라노를 직접 고르고 싶다** — 가장 강하게, 반복해서 요구 ("열 번 눌렀어. 티라노 안 나와") | "공룡 배치는 auto fill만 수행하도록 해 다른 버튼은 필요없어보임" |
| C2 | **직접 배치하고 싶다** ("여기다 놓고 싶은데") | 위와 동일 |
| C3 | **빨리감기** ("거미 싸움 너무 길어") | "배속을 올리는거 없애고" |
| C4 | **거미 빼줘** / 최소한 미리 경고 ("무서워. 아빠 이거 꺼줘") | 방금 추가한 보스 |
| C5 | 전투 중 공룡 직접 조작 (밀기, 던지기) | 관전형이라는 게임의 전제 자체 |
| C6 | 공룡 100마리, 내 공룡 크게, 색 고르기, 이름 짓기 | 신규 기능 (범위 문제) |

## 우선순위 판단

아이가 지루해한 지점은 **10초**였습니다. 그 10초를 못 넘기면 나머지는 의미가 없습니다.
따라서 A군 중에서도 **첫 10초와 마지막 3초**를 고치는 것이 최우선입니다:

1. A1/A2/A3/A4 — 시작 화면에서 헤매지 않고, 실수로 날리지 않게
2. A10 — 시작하자마자 공룡이 보이게
3. A6/A7/A8 — 끝이 보상처럼 느껴지게
4. A5 — 정적을 없애기
5. B1/B2 — 만졌을 때 반응이 오게
6. A9/A11/A12 — 읽히게

## 아직 실기로 확인해야 하는 것

이 보고는 실제 화면 기반이지만 실제 아이는 아닙니다. 다음은 진짜 관찰이 필요합니다:

- 거미가 정말로 무서운지 (에이전트는 무섭다고 했지만 아이마다 다름)
- 오조작 빈도 — 폴드 가로 화면에서 엄지가 실제로 어디에 닿는지
- 10초 지루함이 실제인지, 아니면 조작 불가에서 오는 것인지
